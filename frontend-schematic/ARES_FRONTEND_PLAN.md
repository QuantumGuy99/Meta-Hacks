## Bridging until backend pieces land
- **Contracts:** `src/types/contracts.ts` is generated by S-1 and never hand-edited. Until it exists, write `src/types/contracts.draft.ts` transcribing PLAN §7 + §8.2 message unions; delete it and swap imports the day S-1 merges (one-line change via a `@/types` barrel).
- **Data:** `lib/ws.ts` exposes a `SessionTransport` interface (send ClientMessage / subscribe ServerMessage, reconnect with backoff, `hello` on (re)connect). Real impl = WebSocket to `NEXT_PUBLIC_WS_URL`. Dev-only `FixtureTransport` (behind `NEXT_PUBLIC_FIXTURES=1`, lives in `lib/dev-fixtures/`) plays small JSONL scripts shaped like PLAN §14.6 scenarios (`coding-active`, `defense-bank-transfer`, `report-coding`). Remove once OPS-2 backend MOCK works — PLAN §14.6 makes the backend the real mock.
- **SG/SS libs:** consume `attachEditorCapture`, `codeAt`, and defense selectors through their documented signatures (PLAN §14.3); stub them locally only if they haven't landed when needed, and never edit their files.

## Structure (`frontend/src/`, matches PLAN §6)
```
app/            /  /coding  /coding/[id]  /defense  /defense/[id]  /report/[id]  (+ loading/error per route)
components/
  ui/           shadcn primitives + Ares tokens (PhaseStepper, Timer, LevelChip, SeverityChip, ScoreBar, StatusDot)
  room/         InterviewRoom, Editor, InterviewerPanel, TestPanel, NotesPanel
  coding/       SetupForm, ProblemPanel
  defense/      SamplePicker, AuditView (React Flow), ChaosLab (Recharts), GrillCard, VerifyView, MergeGate
  report/       ReportHeader, DimensionBars, MetricsGrid, MomentCards, Replay (scrubber + read-only Monaco + transcript)
lib/            api.ts  ws.ts  session.ts        (LG)   ·  capture/*, replay.ts (SG)  ·  defense.ts (SS)
types/          contracts.ts (generated)
```
`store.ts`: one zustand store per session — session/phase/remaining_s, interviewer_state, messages, transcript (partial+final), notes, run results, integrity flags, defense audit/metrics/runs/grill/verdict — fed only by ServerMessages.
